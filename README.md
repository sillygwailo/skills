# Human Skills

Skills I have as a human being, not skills for an AI agent. I promise to try as hard as I can to live up to what's written here.

## My Skills

|Skill|Description|
|-----|-----------|
|People skills|Avoiding manipulation as much as I can, I rely on skills learned over a lifetime to further my and other people's goals.|
|Technical skills|An ever-evolving set of abilities involving typing on a keyboard and making a screen output the right thing.|
|Physical skills|Sports, or anything that requires the use of my hands beyond typing on a keyboard.|
|Cooking|Offshoot from physical skills. I've only really started cooking for myself in 2016 at the age of 38, so I still have a long way to go.|
